# Voix-MIDI

Utilisation

Clique sur ● Enregistrer et autorise le micro.
Un décompte de 4 temps se lance, puis tu chantes, siffles ou fredonnes pendant la durée de la boucle (1, 2, 4 ou 8 mesures).
La boucle se lit ensuite en continu. Elle s’affiche sur un piano roll.
Exporter .mid génère le fichier. Dans la version hébergée sur claude.ai, il arrive dans un .zip qui contient le .mid, parce que le .mid brut est refusé.

Réglages

BPM : réglable, 150 par défaut pour ton hard techno.
Quantification : 1/16, 1/8, 1/4 ou aucune.
Gamme et tonique : ils recalent les notes chantées faux sur la gamme choisie.
Octave : décalage de −3 à +3.
Sensibilité du micro : à ajuster selon ton niveau d’entrée.
Sortie MIDI : une sortie directe vers ta DAW est possible (Chrome ou Edge ; sous Windows, il faut loopMIDI).
